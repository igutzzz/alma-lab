# Alma Lab

Site-portfólio da Alma Lab, estúdio criativo independente de design, web e conteúdo visual.

## Executar

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 4173
```

`npm run build` gera o site estático em `dist/client`.
